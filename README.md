# AI 智能体员工系统

> 基于 AI 智能体的自动化业务平台，集成内容创作、线索管理、工作流编排等核心功能。

## 功能特性

### 核心模块

| 模块 | 说明 |
|------|------|
| 数据看板 | 实时数据概览、趋势分析、任务成功率、内容来源分布 |
| AI 员工管理 | 11 个预置智能体，支持启停、手动执行、定时任务、配置管理 |
| 工作流编排 | 可视化节点编辑器，支持拖拽创建、执行状态模拟、运行历史 |
| 内容中心 | 内容创建/编辑/发布、AI 辅助生成、多平台分发、日历视图 |
| 线索管理 | 线索拓取/导入、意向评分、看板视图、跟进记录、批量操作 |
| 系统设置 | AI 服务配置（LLM/TTS/Vision）、Mock 模式、账号管理 |

| 智能体 | 类型 | 功能 |
|--------|------|------|
| 一键追爆 | trend | 热点追踪与爆款分析 |
| AI 创作 | create | 多类型内容自动生成 |
| 数字人 | avatar | 数字人视频生成 |
| 大片自动生成 | video | AI 视频剪辑与制作 |
| AI 拓客 | prospect | 智能线索挖掘与分析 |

| AI 个企微 | wechat | 企业微信自动化运营 |
| AI 人事 | hr | 简历筛选、考勤管理 |
| AI 法务 | legal | 合同审查与生成 |
| AI 电销 | call | 智能外呼与话术生成 |
| AI 直播 | live | 数字人直播自动化 |

## 快速开始

### 环境要求

- Node.js >= 18
- npm >= 9

### 安装依赖

```bash
# 安装后端依赖
cd server && npm install

# 安装前端依赖
cd frontend && npm install
```

### 启动服务

```bash
# 启动后端（端口 3001）
cd server && npm run dev

# 启动前端（端口 3000）
cd frontend && npm run dev
```

## 使用说明

### 数据看板

- **统计卡片**：点击可跳转至对应模块
- **趋势图表**：支持 7 天/30 天切换，实时展示任务/内容/线索趋势
- **导出报告**：点击右上角"导出报告"按钮，生成 CSV 格式数据文件
- **AI 员工状态**：实时显示运行状态，点击可查看详情
- **最近任务/线索**：展示最新 8 条任务记录和 5 条线索

### AI 员工管理

1. **查看列表**：显示所有智能体的运行状态、任务统计
2. **启动/停止**：点击开关控制智能体运行状态
3. **手动执行**：点击"执行"按钮，可传入 JSON 格式参数
4. **查看详情**：点击智能体卡片进入详情页
   - 运行趋势图：支持 7/15/30 天切换
   - 任务日志：状态过滤、详情查看
   - 实时刷新：运行中智能体每 10 秒自动刷新
5. **配置管理**：编辑定时任务（Cron 表达式）和 JSON 配置

### 工作流编排

1. **创建工作流**：点击"新建工作流"，填写名称、描述、触发方式
2. **编辑工作流**：
   - 左侧节点库：拖拽触发器、智能体、动作、条件等节点
   - 画布操作：点击节点连线，拖拽调整位置
   - 节点配置：点击节点打开配置面板，设置名称、关联智能体、输入参数
3. **模拟运行**：点击"模拟运行"，可视化执行过程，节点依次高亮
4. **运行历史**：点击"运行历史"查看过往执行记录
5. **启用/禁用**：列表页开关控制工作流是否激活

### 内容中心

1. **表格/日历视图**：点击右上角切换按钮
2. **创建内容**：
   - 填写标题、选择类型（文章/图片/视频/脚本/文案）
   - 点击"AI 生成内容"自动填充
   - 选择发布平台，保存草稿
3. **发布内容**：
   - 选择目标平台
   - 支持立即发布或定时发布
4. **日历视图**：
   - 按月查看内容发布计划
   - 颜色区分状态：草稿（橙）、待发布（灰）、已发布（绿）
   - 点击事件快速预览
5. **筛选**：按类型、状态过滤内容列表

### 线索管理

1. **表格/看板视图**：点击切换按钮
2. **导入线索**：点击"导入"按钮，上传 JSON/CSV 文件
3. **批量操作**：勾选多条线索后，可批量标记状态或删除
4. **线索详情**：
   - 查看基本信息、评分、状态
   - 跟进记录时间线：展示历史沟通记录
   - 添加跟进：选择类型（电话/拜访/消息/其他），输入记录内容
5. **推进阶段**：点击"推进"按钮，线索自动进入下一阶段
6. **筛选**：按来源、意向等级过滤

### 系统设置

1. **AI 服务配置**：
   - LLM 服务：选择提供商（OpenAI/通义千问/Mock）
   - TTS 服务：语音合成配置
   - Vision 服务：图像生成配置
2. **连接测试**：点击"测试连接"验证配置有效性
3. **账号管理**：修改密码、查看当前用户信息

## 技术架构

### 后端

- **框架**：Express.js + TypeScript
- **数据库**：SQLite（better-sqlite3）
- **认证**：JWT + bcrypt
- **AI 服务**：LLM/TTS/Vision 抽象层，支持多提供商切换

### 前端

- **框架**：Vue 3 + TypeScript + Vite
- **UI 库**：Element Plus
- **图表**：ECharts
- **工作流**：Vue Flow
- **路由**：Vue Router
